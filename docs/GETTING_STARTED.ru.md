# Skill Atlas: руководство для начинающих

[中文](GETTING_STARTED.zh-CN.md) | [English](GETTING_STARTED.en.md) | **Русский**

Это руководство предназначено для пользователей, которые впервые работают с Agent Skills, символическими ссылками или командной строкой.

## 1. Возможности Skill Atlas

| Задача | Команда |
| --- | --- |
| Показать установленные навыки | `manage scan` |
| Проверить обновления, дубликаты и ссылки | `manage status`, `manage dedupe`, `manage sync` |
| Найти конкурентов собственного навыка | `discover competitors` |
| Подобрать навыки для продукта или задачи | `recommend product` или `recommend task` |
| Собрать несколько навыков в процесс | `orchestrate plan` или `orchestrate validate` |
| Периодически повторять анализ конкурентов | `monitor` |

По умолчанию Skill Atlas работает только в режиме чтения. Он не устанавливает, не удаляет, не обновляет и не заменяет навыки без подтверждения.

## 2. Установка

Откройте терминал и выполните:

```bash
git clone https://github.com/Jorgut/skill-atlas.git
cd skill-atlas
python3 scripts/skill_atlas.py install --all-platforms --commands
```

Последняя команда только показывает план. Если конфликтов нет, примените установку:

```bash
python3 scripts/skill_atlas.py install \
  --all-platforms \
  --commands \
  --apply \
  --confirm
```

После установки полностью закройте и снова откройте Codex, OpenCode или Claude Code.

### Что создаёт установщик

- Один основной экземпляр: `~/.agents/skills/skill-atlas`
- Символические ссылки из каталогов выбранных Agent-платформ
- Команду `/skill-atlas` для OpenCode и Claude Code
- Для Codex используется `$skill-atlas`; пользовательская slash-команда там не создаётся

## 3. Первый запуск

### Codex

Введите в чат:

```text
$skill-atlas manage scan
```

Можно использовать обычный запрос:

```text
Используй Skill Atlas, просканируй все локальные навыки и найди дубликаты и символические ссылки.
```

### OpenCode или Claude Code

```text
/skill-atlas manage scan
```

Если команда отсутствует в меню, используйте обычный текст и проверьте раздел устранения неполадок.

### Терминал

```bash
python3 ~/.agents/skills/skill-atlas/scripts/skill_atlas.py manage scan
```

## 4. Типовые сценарии

### Обновления и дубликаты

```text
$skill-atlas manage status
$skill-atlas manage dedupe
$skill-atlas manage sync
```

В OpenCode и Claude Code замените `$skill-atlas` на `/skill-atlas`. Эти команды создают отчёты и планы, но не изменяют ссылки автоматически.

### Конкуренты собственного навыка

```text
$skill-atlas discover competitors closeout
```

Навыки класса `user-authored` защищены: найденные конкуренты используются для сравнения и развития, а не для автоматической замены.

### Подбор навыков для продукта

```text
$skill-atlas recommend product Я хочу создать инструмент проектирования автомобильного HMI --mode balanced
```

Skill Atlas отдельно покажет доступные навыки, порядок работы, пробелы возможностей и внешние модели, плагины, MCP-серверы или интеграции.

Для рекомендаций и оркестрации доступны три режима исследования:

| Режим | Поведение | Когда использовать |
| --- | --- | --- |
| `quick` | Сначала использует локальные навыки и ищет внешние только для отсутствующих возможностей | Быстрый старт |
| `balanced` | Режим по умолчанию; сравнивает каждую возможность с тремя публичными кандидатами, даже если локальный навык уже найден | Обычный выбор для продукта |
| `benchmark` | Ищет восемь кандидатов на возможность и добавляет углублённые запросы по eval, поддержке, лицензии, совместимости и безопасности | Ответственный выбор |

Локальные и публичные кандидаты оцениваются по одной 100-балльной шкале: соответствие задаче 30, качество процесса 20, eval-доказательства 15, поддержка 10, источник и лицензия 10, совместимость 10, безопасность 5.

CLI только создаёт список внешних исследований и сам не выполняет веб-поиск. Статус `provisional` означает, что Agent ещё должен выполнить поиск, проверить исходный код и безопасность, затем оценить кандидатов.

Проверьте комбинацию:

```text
$skill-atlas orchestrate validate Я хочу создать инструмент проектирования автомобильного HMI --mode balanced
```

### Rhino, Blender и SketchUp

```text
$skill-atlas recommend tool Помоги архитектору автоматизировать Rhino, Grasshopper, Blender и SketchUp
```

Результат может включать навыки, настольные приложения, API сценариев, плагины и MCP. Для каждого типа требуется отдельная проверка установки и безопасности.

## 5. Периодическое сравнение конкурентов

Создайте мониторинг:

```text
$skill-atlas monitor add closeout --interval monthly
```

Интервалы: `daily`, `weekly`, `monthly`, `quarterly`.

Проверьте, что уже пора запускать:

```text
$skill-atlas monitor due
```

Попросите Agent выполнить реальный поиск:

```text
$skill-atlas monitor run closeout. Выполни поиск из исследовательского пакета, проверь источники, авторов, лицензии, активность, совместимость и безопасность, затем сохрани результат и сравни его с прошлым периодом.
```

Процесс состоит из двух этапов:

1. Skill Atlas создаёт пакет поисковых заданий.
2. Agent выполняет актуальный веб-поиск и сохраняет проверенные результаты.

Статус `research-required` означает, что завершён только первый этап. Такой мониторинг остаётся просроченным и не считается завершённым сравнением.

История:

```text
$skill-atlas monitor history closeout
```

По умолчанию данные хранятся в `~/.local/share/skill-atlas`.

### Фоновая работа

Skill Atlas не устанавливает скрытый постоянный процесс. Для автоматического запуска используйте Codex Automation, OpenCode Automation, `cron` или macOS `launchd` с заданием:

```text
Используй Skill Atlas и проверь monitor due. Для всех просроченных мониторов выполни веб-поиск, проверку безопасности и сравнение истории. Не заменяй пользовательские навыки.
```

## 6. Значения статусов

- `read-only`: файлы не изменялись
- `research-required`: пакет создан, но внешний поиск не завершён
- `completed`: проверенные результаты сохранены
- `user-authored`: пользовательский навык, автоматическая замена запрещена
- `external-maintained`: навык внешнего автора, обновление возможно только после проверки
- `tool-bundled/cache`: управляется платформой, не редактируйте на месте
- `unknown-local`: происхождение неизвестно, сначала подтвердите источник

## 7. Устранение неполадок

### Нет `/skill-atlas`

- В Codex используйте `$skill-atlas` или обычный текст.
- Для OpenCode и Claude Code установщик должен запускаться с `--commands`.
- Полностью перезапустите приложение.
- Проверьте ссылки:

```bash
ls -l ~/.config/opencode/commands/skill-atlas.md
ls -l ~/.claude/commands/skill-atlas.md
```

### Команда не найдена

```bash
python3 ~/.agents/skills/skill-atlas/scripts/skill_atlas.py --help
```

### Дубликаты найдены, но не объединены

Это нормальная защита. Запустите `manage sync`, изучите план и отдельно подтвердите удаление копий или создание символических ссылок.

### Проверка версии

```bash
python3 ~/.agents/skills/skill-atlas/scripts/skill_atlas.py manage self status
```

Beta-версия не обновляется через сеть без контроля. Сначала проверьте новую версию, затем применяйте `manage self update`.
